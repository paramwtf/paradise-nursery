# Paradise Nursery Shopping Application

## Project Overview
Paradise Nursery is a React-based online houseplant shopping application. Users can explore houseplants, view product details, add products to their cart, update quantities, and calculate the total cost.

## Features
- Responsive landing page
- About Us page
- Plant listing with three categories
- Add to Cart functionality
- Redux Toolkit state management
- Dynamic cart item count
- Increase and decrease quantities
- Remove items from the cart
- Automatic price calculation
- Checkout placeholder

## Technologies Used
- React
- Vite
- JavaScript
- CSS
- Redux Toolkit
- React Redux
- React Router

## How to Run
1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL provided by Vite.
